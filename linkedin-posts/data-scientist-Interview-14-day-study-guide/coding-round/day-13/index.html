1. LRU cache with OrderedDict

Python
What It Solves

Move touched keys to the end; evict from the front.

Why This Is Best

This is the best solution because the data structure matches the operation contract directly. It keeps updates incremental, avoids full recomputation, and makes the time and memory trade-off easy to defend.

Complexity: Time: O(n) for a single pass unless the snippet sorts or builds a larger DP table. Space: O(n) when it stores counts, state, or output.
Example SolutionPython
from collections import OrderedDict

class LRUCache:
    def __init__(self, capacity):
        self.capacity = capacity
        self.cache = OrderedDict()

    def get(self, key):
        if key not in self.cache:
            return -1
        self.cache.move_to_end(key)
        return self.cache[key]

    def put(self, key, value):
        if key in self.cache:
            self.cache.move_to_end(key)
        self.cache[key] = value
        if len(self.cache) > self.capacity:
            self.cache.popitem(last=False)

2. Streaming top k

Python
What It Solves

Maintain counts, then read top k when needed.

Why This Is Best

This is the best solution because the data structure matches the operation contract directly. It keeps updates incremental, avoids full recomputation, and makes the time and memory trade-off easy to defend.

Complexity: Time: O(n) for a single pass unless the snippet sorts or builds a larger DP table. Space: O(n) when it stores counts, state, or output.
Example SolutionPython
from collections import Counter

class TopKStream:
    def __init__(self):
        self.counts = Counter()

    def add(self, item):
        self.counts[item] += 1

    def top_k(self, k):
        return self.counts.most_common(k)

3. Token bucket rate limiter

Python
What It Solves

Refill based on elapsed time.

Why This Is Best

This is the best solution because the data structure matches the operation contract directly. It keeps updates incremental, avoids full recomputation, and makes the time and memory trade-off easy to defend.

Complexity: Time: O(n) for a single pass unless the snippet sorts or builds a larger DP table. Space: O(n) when it stores counts, state, or output.
Example SolutionPython
import time

class TokenBucket:
    def __init__(self, capacity, refill_per_sec):
        self.capacity = capacity
        self.tokens = capacity
        self.refill_per_sec = refill_per_sec
        self.updated_at = time.time()

    def allow(self):
        now = time.time()
        self.tokens = min(self.capacity, self.tokens + (now - self.updated_at) * self.refill_per_sec)
        self.updated_at = now
        if self.tokens >= 1:
            self.tokens -= 1
            return True
        return False

4. Reservoir sampling

Python
What It Solves

Uniform sample from a stream of unknown length.

Why This Is Best

This is the best interview solution because it uses the simplest pattern that reaches the target complexity, keeps edge cases visible, and leaves you with code you can explain line by line.

Complexity: Time: O(n) for a single pass unless the snippet sorts or builds a larger DP table. Space: O(n) when it stores counts, state, or output.
Example SolutionPython
import random

def reservoir_sample(stream, k):
    sample = []
    for i, item in enumerate(stream, start=1):
        if i <= k:
            sample.append(item)
        else:
            j = random.randint(1, i)
            if j <= k:
                sample[j - 1] = item
    return sample

5. Parse event log into sessions

Python
What It Solves

Start a new session after inactivity.

Why This Is Best

This is the best interview solution because it uses the simplest pattern that reaches the target complexity, keeps edge cases visible, and leaves you with code you can explain line by line.

Complexity: Time: O(n) for a single pass unless the snippet sorts or builds a larger DP table. Space: O(n) when it stores counts, state, or output.
Example SolutionPython
from datetime import timedelta

def sessionize(events, gap_minutes=30):
    sessions, current = [], []
    gap = timedelta(minutes=gap_minutes)
    for event in sorted(events, key=lambda e: e["ts"]):
        if current and event["ts"] - current[-1]["ts"] > gap:
            sessions.append(current)
            current = []
        current.append(event)
    if current:
        sessions.append(current)
    return sessions

6. Sessionization

SQL
What It Solves

Flag new sessions, then cumulative-sum the flags.

Why This Is Best

This is the best interview solution because it computes the metric at the correct grain, names the intermediate logic clearly, and handles edge cases such as nulls or zero denominators where they matter.

Complexity: Cost depends on table size, indexes, and partition cardinality; the important interview point is the row grain and join/window order.
Example SolutionSQL
WITH ordered AS (
  SELECT *,
         LAG(event_time) OVER (PARTITION BY user_id ORDER BY event_time) AS prev_time
  FROM events
),
flagged AS (
  SELECT *,
         CASE WHEN prev_time IS NULL OR event_time > prev_time + INTERVAL '30 minute' THEN 1 ELSE 0 END AS new_session
  FROM ordered
)
SELECT *,
       SUM(new_session) OVER (PARTITION BY user_id ORDER BY event_time) AS session_number
FROM flagged;

7. First-touch attribution

SQL
What It Solves

Rank touchpoints before purchase.

Why This Is Best

This is the best interview solution because it computes the metric at the correct grain, names the intermediate logic clearly, and handles edge cases such as nulls or zero denominators where they matter.

Complexity: Cost depends on table size, indexes, and partition cardinality; the important interview point is the row grain and join/window order.
Example SolutionSQL
WITH touches AS (
  SELECT p.purchase_id,
         m.channel,
         ROW_NUMBER() OVER (PARTITION BY p.purchase_id ORDER BY m.touch_time) AS rn
  FROM purchases p
  JOIN marketing_touches m
    ON m.user_id = p.user_id
   AND m.touch_time <= p.purchase_time
)
SELECT channel, COUNT(*) AS attributed_purchases
FROM touches
WHERE rn = 1
GROUP BY channel;
