1. Longest substring without repeats

Python
What It Solves

Jump the left pointer past the last duplicate.

Why This Is Best

This is the best solution because the window keeps only the active state instead of recomputing every candidate range. Each pointer moves forward, so the solution stays linear and the edge cases remain local.

Complexity: Time: O(n) for a single pass unless the snippet sorts or builds a larger DP table. Space: O(n) when it stores counts, state, or output.
Example SolutionPython
def longest_unique_substring(s):
    last_seen = {}
    left = best = 0
    for right, ch in enumerate(s):
        if ch in last_seen and last_seen[ch] >= left:
            left = last_seen[ch] + 1
        last_seen[ch] = right
        best = max(best, right - left + 1)
    return best

2. Max sum subarray of size k

Python
What It Solves

Fixed window: add new, remove old.

Why This Is Best

This is the best solution because it defines a compact state, reuses previous work, and avoids exponential recomputation. Where possible, the state is compressed so the code is both fast and interview-readable.

Complexity: Time: O(n) for a single pass unless the snippet sorts or builds a larger DP table. Space: O(n) when it stores counts, state, or output.
Example SolutionPython
def max_sum_k(nums, k):
    window = sum(nums[:k])
    best = window
    for i in range(k, len(nums)):
        window += nums[i] - nums[i - k]
        best = max(best, window)
    return best

3. Minimum length subarray at least target

Python
What It Solves

Expand to satisfy, contract to optimize.

Why This Is Best

This is the best solution because it defines a compact state, reuses previous work, and avoids exponential recomputation. Where possible, the state is compressed so the code is both fast and interview-readable.

Complexity: Time: O(n) for a single pass unless the snippet sorts or builds a larger DP table. Space: O(n) when it stores counts, state, or output.
Example SolutionPython
def min_len_at_least(nums, target):
    left = total = 0
    best = float("inf")
    for right, x in enumerate(nums):
        total += x
        while total >= target:
            best = min(best, right - left + 1)
            total -= nums[left]
            left += 1
    return 0 if best == float("inf") else best

4. Moving average

Python
What It Solves

Queue-free fixed window using a running sum.

Why This Is Best

This is the best solution because the window keeps only the active state instead of recomputing every candidate range. Each pointer moves forward, so the solution stays linear and the edge cases remain local.

Complexity: Time: O(n) for a single pass unless the snippet sorts or builds a larger DP table. Space: O(n) when it stores counts, state, or output.
Example SolutionPython
def moving_average(values, k):
    out, total = [], 0
    for i, value in enumerate(values):
        total += value
        if i >= k:
            total -= values[i - k]
        if i >= k - 1:
            out.append(total / k)
    return out

5. At most k distinct values

Python
What It Solves

A useful template for segmentation questions.

Why This Is Best

This is the best solution because the window keeps only the active state instead of recomputing every candidate range. Each pointer moves forward, so the solution stays linear and the edge cases remain local.

Complexity: Time: O(n) for a single pass unless the snippet sorts or builds a larger DP table. Space: O(n) when it stores counts, state, or output.
Example SolutionPython
from collections import defaultdict

def longest_at_most_k_distinct(values, k):
    counts = defaultdict(int)
    left = best = 0
    for right, value in enumerate(values):
        counts[value] += 1
        while len(counts) > k:
            counts[values[left]] -= 1
            if counts[values[left]] == 0:
                del counts[values[left]]
            left += 1
        best = max(best, right - left + 1)
    return best

6. Clean then aggregate with CTEs

SQL
What It Solves

Name every step so the query debugs cleanly.

Why This Is Best

This is the best interview solution because it computes the metric at the correct grain, names the intermediate logic clearly, and handles edge cases such as nulls or zero denominators where they matter.

Complexity: Cost depends on table size, indexes, and partition cardinality; the important interview point is the row grain and join/window order.
Example SolutionSQL
WITH clean_orders AS (
  SELECT *
  FROM orders
  WHERE status = 'paid' AND amount > 0
),
daily AS (
  SELECT order_date::date AS day, SUM(amount) AS revenue
  FROM clean_orders
  GROUP BY 1
)
SELECT *
FROM daily
ORDER BY day;

7. Users active in first 7 days

SQL
What It Solves

Join signup date to bounded activity dates.

Why This Is Best

This is the best interview solution because it computes the metric at the correct grain, names the intermediate logic clearly, and handles edge cases such as nulls or zero denominators where they matter.

Complexity: Cost depends on table size, indexes, and partition cardinality; the important interview point is the row grain and join/window order.
Example SolutionSQL
SELECT u.user_id,
       COUNT(DISTINCT a.activity_date) AS active_days_7d
FROM users u
LEFT JOIN activity a
  ON a.user_id = u.user_id
 AND a.activity_date >= u.signup_date
 AND a.activity_date < u.signup_date + INTERVAL '7 day'
GROUP BY u.user_id;

8. Daily revenue plus 7-day rolling sum

SQL
What It Solves

Aggregate first, then window over the daily grain.

Why This Is Best

This is the best interview solution because it computes the metric at the correct grain, names the intermediate logic clearly, and handles edge cases such as nulls or zero denominators where they matter.

Complexity: Cost depends on table size, indexes, and partition cardinality; the important interview point is the row grain and join/window order.
Example SolutionSQL
WITH daily AS (
  SELECT order_date::date AS day, SUM(amount) AS revenue
  FROM orders
  GROUP BY 1
)
SELECT day,
       revenue,
       SUM(revenue) OVER (ORDER BY day ROWS BETWEEN 6 PRECEDING AND CURRENT ROW) AS revenue_7d
FROM daily;
